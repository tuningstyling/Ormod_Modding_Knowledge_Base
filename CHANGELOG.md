# Changelog

Newest first. "KB" is the version of this knowledge base; mod versions are the ones whose code or findings the entry covers.

- Status labels re-checked: a few were lowered from [IN-GAME] to [TESTED] or [ASSUMED] where no in-game evidence exists.
- Covers: Heechee_ExtraMusic up to 1.4.2 (as delivered; the 1.3.1 audio-device fix by another agent is described but its player code has not been seen).
